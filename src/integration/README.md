# Third-Party Integration Directory

This directory contains the integration infrastructure for third-party dependencies.

## Structure

- `extracted/` - Integrated third-party source code with full attribution
- `metrics/` - Integration performance metrics and logging
- `manifests/` - Integration manifests and dependency metadata

## Integration Guidelines

All third-party library source code must be integrated with:
1. Complete attribution headers with SPDX identifiers
2. SHA-256 integrity verification
3. Namespace adaptation (if necessary)
4. License compliance validation

See the project constitution section VI for detailed requirements.
